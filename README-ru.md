# PC Style Shortcuts

Подменяет сочетания клавиш на привычные с PC (Windows/Linux) и позволяет настроить любую привязку.

## Возможности

- Готовые PC Style-значения по умолчанию (Ctrl+C/V, Home/End, прыжки по словам и другое)
- Одно окно настроек: ремаппинг, Accessibility, автозапуск, внешний вид и все клавиши
- Включение/выключение каждого действия и своя комбинация
- Категории: Язык, Редактирование, Навигация, Окно, Браузер
- Сброс всех привязок к PC Style одной кнопкой
- Умный Ctrl+C/Z/X в терминале: без выделения остаются команды shell; с выделением или в редакторе - копирование/отмена (можно выключить)
- Смена языка: **⌥⇧** следующая раскладка, **⌥⌃** предыдущая (без Space)
- Запуск при входе в систему, опциональная иконка в Dock
- Интерфейс на английском и русском

## Установка

1. Откройте `PCStyleShortcuts.xcodeproj` в Xcode 27.2+
2. Запустите **PCStyleShortcuts**
3. Системные настройки -> Конфиденциальность и безопасность -> Универсальный доступ -> включите приложение  
   (или кнопка **Open Accessibility Settings** в приложении)
4. Настройте клавиши: строка меню -> **Settings...**

## Основные сочетания по умолчанию

| Действие                                  | По умолчанию                |
| ----------------------------------------- | --------------------------- |
| Копировать / Вставить / Вырезать / Отмена | Ctrl+буква -> Cmd+буква     |
| Повтор                                    | Ctrl+Shift+Z -> Cmd+Shift+Z |
| Home / End                                | -> Cmd+<- / Cmd+->          |
| Прыжок по словам                          | Ctrl+<-/-> -> Option+<-/->  |
| Следующая / предыдущая раскладка          | ⌥⇧ / ⌥⌃                     |
| Zoom / обновление в браузере              | Выключено, пока не включите |

## Разработка

```bash
xcodebuild -scheme PCStyleShortcuts -destination 'platform=macOS' build
xcodebuild -scheme PCStyleShortcuts -destination 'platform=macOS' test
```
